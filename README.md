# Portfólio de projetos

Este repositório reúne documentação de projetos de desenvolvimento web e modelagem 3D. Cada documento descreve o objetivo, as tecnologias e o estado conhecido do projeto.

## Projetos

- [Lume Eventos](docs/lume-eventos.md) — prévia de uma plataforma de convites e controle de entrada para festas.
- [Suporte para interruptor](docs/suporte-interruptor.md) — protótipo mecânico de uma caixa para interruptor.
- [Sapatinhas para os pés da mesa](docs/pes-de-mesa.md) — projeto de peças 3D para elevar e envolver os pés de uma mesa.

## Sobre este repositório

Este repositório contém documentação. O código-fonte e os modelos STL/3MF permanecem nos respectivos projetos locais e não foram copiados para cá.
